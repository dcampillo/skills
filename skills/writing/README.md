# Writing skills

| Skill | Description |
| --- | --- |
| [`human-voice`](human-voice/SKILL.md) | Apply this skill when the user explicitly asks for human-sounding output. Strips AI clichés and puffery to produce plain, specific, conversational text. |
| [`minto-writer`](minto-writer/SKILL.md) | Writes or restructures business content answer-first using Barbara Minto's Pyramid Principle and the SCQA framework. |
| [`tldr`](tldr/SKILL.md) | Produces a structured TLDR summary (headline, key points, key takeaway) of pasted text or a URL. |
| [`to-outline`](to-outline/SKILL.md) | Writes or updates structured pages in an Outline wiki, stores real config files next to them with secrets redacted, and marks pages for review. |
