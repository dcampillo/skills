## Purpose

This page defines where documentation goes. The to-outline skill reads it at the start of every run, so editing it changes where new pages land. The collections and top-level pages below are the stable part. At run time, the skill also reads the live tree of the chosen collection to find the exact parent page.

## Top-level pages

Each collection keeps up to five top-level pages, and none is a catch-all such as "Misc". If something does not fit, the skill proposes a new parent page and waits for your yes. After you approve a new parent page or a new collection, the skill adds it to this page so the page stays in sync with the real structure.
